# TrendJack (dev)

This is the development build of the TrendJack plugin. It is generated from `plugins/trendjack` by `scripts/build-dev.mjs`, so do not edit it by hand. It has the same skills, but its connector points at https://app.dev.trendjack.io/api/mcp instead of the production server. Use it to test skill and server changes on the dev deployment before they reach the production plugin. It is for the TrendJack team only. Sign in with your account on the dev deployment, not your production account.
